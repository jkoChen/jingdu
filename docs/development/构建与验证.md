# 构建与验证

在仓库根目录执行。桌面使用 CMake 3.16 以上、C/C++17 工具链和 Python 3.9 以上。Linux 还需 OpenSSL 开发包。目标板使用 PlatformIO Core，平台版本固定于 platformio.ini。首次板端构建需取得工具链，随后可复用 PlatformIO 自己的包缓存。

```sh
./tests/run.sh
./scripts/build.sh
python3 scripts/package.py
```

测试使用临时卡目录及 ASan/UBSan。桌面可检查解码、渲染输出、网络协议和持久化。目标板构建检查编译、链接和分区容量。发行脚本核对镜像头、版本、镜像摘要，并按 [随卡清单](../../tf/manifest.json) 生成 ZIP，逐文件解包核验。产物在 artifacts/，SHA256SUMS 同时覆盖镜像和卡包。公开包之外的资料可以按设备目录自行导入。

英语字形由 [生成器](../../scripts/study_font.cpp) 读取 Atkinson Medium 和 DejaVu 音标，锁屏字形由 [时钟脚本](../../scripts/clock_font.py) 读取霞鹜臻楷。原件版本以 [字体来源清单](../../assets/fonts/README.md) 的摘要识别。普通构建直接使用已有点阵。更新原件后运行以下命令并检查生成差异。时钟脚本需要 Pillow，文泉驿 UI 字体的独立生成入口是 scripts/ui_font.py，接受原版 9pt、11pt BDF 所在目录与目标文件路径。

```sh
cmake --build .local/host --target jingdu_study_font
.local/host/jingdu_study_font > src/generated/study_font.inc
python3 scripts/clock_font.py
```

真机性能对照固定设备、卡、书、位置、字号和全刷间隔。冷建须从派生索引为空的测试卡目录开始，测至首屏并核对目录目标。分别测停读后翻页、百页连翻和跨章，记录输入来源、触点到刷完耗时、面板 BUSY 和最大连续内部字节堆；重复切书后回到同一页面对照内存。原始测量留在本地，稳定结论与适用条件才收入正式文档。

只改文档时可单独运行 `python3 tests/docs_test.py`。它检查全部设备页面在设计稿和指南中的覆盖，检查仓库内链接、设计稿原生图和指南配图；不代表在实机上复验过相应功能。

## 分享源码与配图

从已审核的提交导出源码。在仓库根目录运行以下命令，得到带顶层目录的 ZIP。包内只含该提交的文件，适合交给其他人构建或二次开发。固件镜像和随卡 ZIP 由上面的发行命令单独生成。

```sh
mkdir -p artifacts
git archive --format=zip --prefix=jingdu/ --output=artifacts/jingdu-source.zip HEAD
```

分享 Git 仓库时，提交历史会公开作者名和提交邮箱。分享源码 ZIP 时，保留源码、字体和教学资料自带的署名与许可。检查最终准备发送的 ZIP 条目和文档图片，尤其是书架、Wi-Fi、配对和投送设置页。以自制样书和示例凭据制作配图。原始照片、串口记录、设备闪存和卡上 `/.jingdu/` 存在本地工作目录。

公开照片以锁屏时钟和随卡样书《沿河散步》的正文为宜。使用素色背景和侧面自然光，画面只留机身，发布前去掉照片定位、拍摄设备和作者等元数据。实拍图注明机型和固件版本，与 240 × 416 的实机回读图分别标注。
