# 阅读、学习与资料导入

## 在设备上的操作

- **锁屏与按键**　锁屏显示时钟、公历年月日、星期、农历、温湿度及电量。农历数据来自[香港天文台公历与农历对照表](https://www.hko.gov.hk/sc/gts/time/conversion.htm)，在本机离线换算，覆盖 2020–2099 年。侧键单击唤醒。在阅读或支持翻页的列表内，唤醒后单击前进。双击进入睡眠，判定窗口为 280 ms。一次唤醒按压会被消费。前光在休眠时关闭。
- **书架与文件**　从「书架 → 添加」或「文件管理」选取卡上的 TXT、EPUB，点「加入书架」。书架显示每本书进度。首页「继续阅读」直达上次确认显示的位置。书架、英语练习、文件管理和设置各用一枚 18 × 18 单色图标。
- **阅读**　轻点正文中央打开菜单，可进入章节目录、书签和进度跳转。进度每档 5%，可回到跳转前的位置。正文左上角的小房子会保存进度并返回首页。正文底边显示细进度条和百分比，可在「阅读菜单 → 阅读排版 → 显示阅读进度」关闭，让正文延伸至底边。按住正文约 0.4 秒后向下拉至少 48 像素，松手即可添加或取消本页书签。书签标记位于正文右上角。
- **快捷设置**　从已唤醒的普通页面自顶部下拉，可点亮度刻度直接选 0–10 档，点两端的太阳微调，也可选择全刷间隔或立即清屏。列表分页和返回保留原页。
- **校时**　「设置 → 日期与时间」可在连好 Wi-Fi 后点「联网校时」。离线时进入「手动校时」，选择年、月、日、时或分，调整后点「保存时间」。界面使用北京时间。
- **英语练习**　「英语练习 → 选择课包」切换课程和 OneStopQA 难度。「选择篇目」列出当前课包中的文章，阅读中也可点左下「篇目」直接换篇。短句、长句和短篇可配理解题、原文依据和拆句。学习页可以查卡上的词典、存生词、重做错题。英文正文采用 Atkinson Hyperlegible Next Medium 20 px，拉丁字形内置于固件。长选项先展开，明确选择后再点「核对答案」。
- **切换正文字体**　在「阅读排版 → 正文字体」选择卡上的 TTF 或 OTF。准备页显示当前页的排版与渲染进度。完成后自动回到排版。
- **全刷间隔**　在「设置」或「快捷设置」选择 5、10、20、50、100 页。默认 10 页。
- **无线与文件服务**　「设置 → Wi-Fi」开启并选中网络。在小屏键盘输入密码，可切换大小写、数字、符号和显隐。连好 Wi-Fi 并挂载 TF 后，在「设置 → 文件服务」手动开启，电脑或手机打开屏上地址，用六位码配对。码五分钟有效，可点「更新配对码」换码。
- **浏览器管理卡**　书籍、字体和英语练习各有上传入口，分别写入 /books、/fonts 和 /courses/english。支持列目录、新建目录、上传、下载、改名及删除。一次一个传输，上传最大 32 MiB。同名上传返回冲突，需要新名字或先处理旧文件。活动资源和内部状态目录受保护。睡眠、断网、换卡会停止服务。连接使用本地 HTTP。

## 导入自己的资料

| 类型 | TF 位置 | 文件准备 |
| --- | --- | --- |
| 书籍 | 例如 /books | TXT 和无 DRM 的可重排 EPUB 可从文件管理打开，再手动加入书架。TXT 支持 UTF-8、GB18030、带 BOM 的 UTF-16/32。 |
| 字体 | /fonts | 未指定字体时优先尝试方正屏显雅宋，其次为随包的霞鹜臻楷 Slab GB；在阅读排版里可以换成其他兼容 TTF/OTF。字体无法使用时退回内置点阵。 |
| 英语题目 | /courses/english | 小课包可以直接照 [JSON 示例](../../tf/courses/english/everyday-starter.json) 填写。24 KiB 以上的 JSON 或现成 OneStopQA、H5P、CSV 资料在电脑上转换为 .jdc。每个独立阅读段上限 16 KiB。 |
| 英汉词典 | /dictionaries/词典名 | 使用 32 位偏移的 StarDict。基本文件为同名 .ifo、.idx 和 .dict。电脑导入工具可展开 .dict.dz 和 .idx.gz，并将 .syn 别名与词头编成 .jdx。 |

在工程目录运行以下示例。末尾的路径是电脑上的输出位置，转换结果再放入卡上对应的目录。Python 导入工具使用标准库。

```sh
python3 scripts/import_course.py 我的课程.csv 我的课程.jdc
python3 scripts/import_course.py onestop-qa.zip OneStopQA-Int.jdc --level Int
python3 scripts/import_course.py Pronouns.h5p Pronouns.jdc
python3 scripts/import_dictionary.py 下载的StarDict词典.zip 准备好的词典目录
```

CSV 表头为 `id,title,text,question,a,b,c,d,answer,evidence`，`answer` 从 1 到 4。H5P 转换器支持 Single Choice Set。OneStopQA 的三个难度使用同一套理解题，同一题在三个难度中的正文不同。随包资料的作者、原许可及改编说明见[资料来源](../../tf/资料来源/来源.md)。
