# TF 卡目录与文件

以下目录以 TF 卡根目录为起点。固件里的 `/sd` 是挂载点。目录按使用功能建立，新卡上可能只出现其中一部分。此清单说明固件的文件组织。

## 卡根目录

| 路径 | 内容与来源 |
|---|---|
| `/books/` | 传书的默认位置，接受 TXT 和 EPUB。文件管理也可以从卡上其他普通目录打开书。加入书架只记录原路径，书不会被再复制一份。 |
| `/fonts/` | 用户导入的 TTF、OTF，以及可能随字体附带的许可文件。字体渲染产生的长期缓存写入隐藏目录。 |
| `/courses/english/` | 英语课包，一个课包对应一个 `.jdc` 或 `.json` 文件。学习进度另存。 |
| `/dictionaries/` | StarDict 词典，可放在这里或它的一级子目录。每套词典的基本文件为同名 `.ifo`、`.idx`、`.dict`，可附 `.syn` 和电脑导入时生成的快速索引 `.jdx`。换卡时一起复制。 |
| `/资料来源/` | 导入资源的来源说明、许可和选题索引，随资源写入。 |
| `/.jingdu/user/` | 静读个人存档，包含书签、阅读位置、书架和学习记录。应备份。 |
| `/.jingdu/cache/` | 静读自动生成的阅读缓存和 EPUB 工作文件。退出阅读并停止访问卡后可清理，后续按需重新生成。 |

阅读器的文件管理和局域网文件服务会隐藏点号开头的项目。Mac 访达在卡根目录按 ⌘⇧. 可查看隐藏目录。Wi-Fi 凭据在 ESP32 内部 NVS。设置在机身和卡上各有一份，启动时优先读取机身。最近阅读随卡保存。有卡休眠时，机身只保存本次恢复记录的摘要，唤醒时与当前卡核对。无卡休眠时，机身保存可恢复的页面状态。

## 个人存档文件

以下路径都相对于 `/.jingdu/user/`。表中每个文件末尾实际带 `.0` 或 `.1`。首次写入只有一份，内容变化时交替写入。读取时校验两份并选最新有效版本，备份时保留两份。

| 文件名模式 | 存什么 |
|---|---|
| `settings` | 亮度、全刷间隔、自动锁屏、字体路径、字号、排版、进度显示、所选课包与词典等。 |
| `shelf/.recent` | 当前卡最近阅读的原文件路径。已入架的书以加号标记，显示前检查收录记录。升级时自动读取旧卡上的 `recent` 并迁移有效路径。 |
| `wake` | 本卡最近一次休眠保存的页面状态，用于返回原页面。 |
| `shelf/<书籍内容哈希>/ref` | 每本书的书架条目，内容指向原文件。 |
| `shelf/p-<路径哈希>/ref` | 刚加入书架的原路径，确认内容版本后合并到上面的书架条目。 |
| `shelfby/<路径哈希>` | 从已收录路径找到书架条目的内容哈希。 |
| `draft/<路径哈希>` | 版本尚在核对时已显示的阅读位置及落点凭据，合并成功后写入空记录。 |
| `draftmarks/<文件指纹>` | 核对期间新加的书签，确认后合并。指纹包括路径、大小、时间和抽样。 |
| `locator/<书籍路径哈希>` | 从原路径找到书籍内容标识，用于续读。 |
| `positions/<书籍内容哈希>` | 该书最近一次保存的章节、字节位置、百分比、原路径和续读落点凭据。 |
| `marks/<书籍内容哈希>` | 该书的全部书签，包括章节、位置和摘录。 |
| `study/<课包路径哈希>` | 当前篇目、练习段落及作答状态。 |
| `answers/<题目标识哈希>` | 该题首次作答是否正确。 |
| `errors/<题目标识哈希>/item` | 错题本条目。 |
| `vocab/<单词哈希>/item` | 生词本条目和复习记录。 |

例如 `settings.0`、`settings.1` 是同一个设置记录的两代。哈希名由固件生成，不需要手工改名。换卡时保留书的目录和文件名，一起复制原书和整个 `/.jingdu/user/`，这样书架引用和最近阅读仍能找到原书。

## 自动生成的缓存文件

以下路径相对于 `/.jingdu/cache/`。当前版本按文件名前缀区分用途，目录内没有按书名创建子文件夹。

| 文件名模式 | 用途 |
|---|---|
| `identity-v1/<两位十六进制>.0`、`.1` | 书籍完整版本和局域网上传时得到的书籍或字体版本，共 256 个槽，按需写入。选字体可以复用这里已有的匹配记录。记录相对路径、大小、修改时间、完整 SHA-256 和抽样摘要。槽冲突会使被替换的文件在下次需要时重新核对。 |
| `glyph-<1位十六进制>` | TTF 字形的黑白点阵、占宽和偏移。同字体、字号、墨色可跨书复用。每个文件 512 个散列槽，碰撞时复用槽位。这是 0.2.1 及更早版本留下的可重建缓存。 |
| `glyph2-<64位十六进制哈希>` | 从 0.2.2 起使用的增量字形库，每种字体、字号、墨色一份。0.2.4 选字体时由表目录、文件大小、修改时间和固定样本辨别版本，命中旧完整摘要记录可沿用旧库。字形记录按需追加，索引冲突时仍保留已有字形；每份最多 65,535 条，写入受卡缓存预算限制。 |
| `page-<1位十六进制>-<0至7>` | 已画好的正文页及校验信息。每本书映射到一组八个可复用槽，不会为每读一页永久新增一个文件。 |
| `index-<排版哈希>-<章节号>` | 连续分页的字节起止位置，供回翻。同一书、同一章节换字号后可能产生新的索引文件。 |
| `glyph2-<哈希>.warm.0 / .warm.1` | 0.2.8 空闲预热的双份进度记录。随对应字形库清理后可从头重新预热。 |
| `toc-<书籍内容哈希>` | 从 TXT 提取的章节目录。构建中为同名 `.work`，完成记录为 `.done.0` 或 `.done.1`。 |
| `catalog2-<8位路径哈希>` | 大型或内存紧张时使用的 EPUB 资源与目录索引。新索引先写入 `.part`，替换时短暂保留 `.old`。冷建可用 `.inflate` 保存解压历史，超过 1,024 个 ZIP 条目时还会用 `.tables` 暂存查找表。 |
| `chapter-<2位十六进制>` | 从 EPUB 展开的当前或近期章节。构建中为 `.part`，完成校验为 `.stamp.0` 或 `.stamp.1`；特定解压路径还会使用 `.part.inflate`。 |

`.inflate` 是 EPUB 解压专用的 TF 历史窗口，正常结束后释放。当前系统没有通用内存交换文件。缓存写入预算取 64 MiB 与卡容量 5% 中较小者，并为其他用途预留 16 MiB。需要腾空间时现有回收逻辑优先在旧的 `page-`、`index-` 文件中选择，其他缓存也可能积累。手工清理只选 `cache`，勿连同同级的 `user` 一起删除。

## 传输时出现在目标目录的两个文件

| 临时路径 | 生成时机 |
|---|---|
| `<上传目标目录>/.jingdu-upload` | 局域网文件服务正在接收一个文件。例如传一本书时为 `/books/.jingdu-upload`。传完再改为目标文件名。 |
| `/fonts/.jingdu-font.tmp` | USB 工具导入或复制字体时暂存。成功并校验后再改名。 |

这些文件暂时和目标文件放在一起，正常完成后消失。强制断电可能留下临时文件。阅读、练习和查词都不会在每本书或每个课包旁边生成个人存档。
