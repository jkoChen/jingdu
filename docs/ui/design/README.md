# 页面交互设计稿

在本地浏览器打开 [index.html](index.html)，可在 240 × 416 原生像素、两倍放大和可校准的实物尺寸间切换。在代码托管网站看见 HTML 源码时，请先克隆或下载仓库。本稿离线可用；页内选择、示例密码和重启都只在浏览器中演示。

| 入口 | 可以验证什么 |
| --- | --- |
| [首页](index.html#home) · [阅读正文](index.html#book) | 续读、两侧翻页、中央菜单、下拉书签、页脚开关 |
| [英语练习](index.html#learn) | 换篇、长选项、作答、反馈和词典 |
| [设置](index.html#settings) · [无线墨屏](index.html#screenCanvas) | 一屏八行、连接信息、日期与电源 |
| [全部页面](index.html#全部页面) | 按功能浏览各页，展开状态或显示触控热区 |
| [网页文件服务](files.html) | 手机、电脑端配对和文件操作；示例码 **381624**，操作不访问设备 |

`screens.js` 存页面、状态及热区，`interaction.js` 实现设计稿导航，`pixels.js` 保存去重后的原生位图。设备上的真实行为由固件决定。配图不使用个人书库、真实网络凭据或旧实拍照片；课包样例的[出处和许可](../../../tf/资料来源/来源.md)随项目提供。

与[界面设计规范](../静读界面与交互设计规范.md)一起评审。交互改动先改本稿，经审核后改固件，再更新[完整功能指南](../../guides/完整功能指南.md)和受影响的配图。
