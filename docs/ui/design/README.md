### 章节目录完成后再进入阅读

第一次打开 TXT，读取完整原文以识别章标题，按已扫描字节显示进度。扫描完成并成功发布目录后才进入阅读。中途点「返回」回到开书入口，下次从已保存的断点继续。读取失败、写卡失败或目录超出可处理范围时，提示原因和返回路径。扫描成功且零条标题也是有效结果，正文可以照常阅读。

重开同一版本的书直接使用已完成的目录，只读当前目录页所需的条目。打开目录定位到当前章，读者手动翻页时维持所选页。换字号、换字体不会触发重新扫描。大型 EPUB 使用自身的完整目录索引，无目录的 EPUB 沿用书内阅读顺序。

字形的「立即阅读」及约 2 秒上限在目录完成后才生效。目录完成不要求缓存全书字形、全部页图或解压所有章节。

`screens.js` 存页面、状态及热区，`interaction.js` 实现设计稿导航，`pixels.js` 保存去重后的原生位图。设备上的真实行为由固件决定。配图不使用个人书库、真实网络凭据或旧实拍照片；课包样例的[出处和许可](../../../tf/资料来源/来源.md)随项目提供。

与[界面设计规范](../静读界面与交互设计规范.md)一起评审。交互改动先改本稿，经审核后改固件，再更新[完整功能指南](../../guides/完整功能指南.md)和受影响的配图。
