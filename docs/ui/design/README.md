### 章节目录完成后再进入阅读

第一次打开 TXT，读取完整原文以识别章标题，按已扫描字节显示进度。扫描完成并成功发布目录后才进入阅读。中途点「返回」回到开书入口，下次从已保存的断点继续。读取失败、写卡失败或目录超出可处理范围时，提示原因和返回路径。扫描成功且零条标题也是有效结果，正文可以照常阅读。

重开同一版本的书直接使用已完成的目录，只读当前目录页所需的条目。打开目录定位到当前章，读者手动翻页时维持所选页。换字号、换字体不会触发重新扫描。大型 EPUB 使用自身的完整目录索引，无目录的 EPUB 沿用书内阅读顺序。

字形的「立即阅读」及约 2 秒上限在目录完成后才生效。目录完成不要求缓存全书字形、全部页图或解压所有章节。

### 电量状态

电量沿用状态栏中的百分比和电池图标，不增加页面或触区。有效读数默认按 1750 对应 0%、2400 对应 100% 换算，手动校准后使用本机参考值，中间各档同比调整；ADC 为零或饱和时使用既有未知状态「--%」。百分比只是估算，界面 100% 不作为充电结束提示。[采样及诊断说明](../../hardware/WDD-2026V1.md#电池采样与电量曲线)。

### 手动满电校准

[原生点阵交互稿](battery-calibration.html)以现有字体、页头、设置行和按钮尺寸绘制，示例参考值不来自自动满电识别。该入口已按确认稿实现于 0.2.23。

新增「设置 → 电源 → 电量校准」。用户充电至指示灯熄灭、拔掉电源线后点击开始；等待 30 秒，再按 10 秒间隔采集 5 组读数。每组取三次 ADC 中位数，最后取五组中位数；任一组偏离结果超过 25，不保存。首次完整等待约 70 秒。稳定后由用户明确点击「保存为满电」，不自动提交。

本机校准值保存在静读自己的机身设置中，原厂 `SystemSetting/BatCal` 保留。默认或恢复默认使用 2400。取消、无效读数、波动过大、写入失败均保留原参考；保存失败可直接重试有效结果。返回电源仍在一屏，已有校准时提供「恢复默认」。它只改变电量显示的换算端点，不改变充电控制，不测量电池容量或健康度。

`screens.js` 存页面、状态及热区，`interaction.js` 实现设计稿导航，`pixels.js` 保存去重后的原生位图。设备上的真实行为由固件决定。配图不使用个人书库、真实网络凭据或旧实拍照片；课包样例的[出处和许可](../../../tf/资料来源/来源.md)随项目提供。

与[界面设计规范](../静读界面与交互设计规范.md)一起评审。交互改动先改本稿，经审核后改固件，再更新[完整功能指南](../../guides/完整功能指南.md)和受影响的配图。
