# 静读界面与交互设计规范

**v1.0 正式规范 · 2026-11-11 经项目负责人确认生效**

适用于武哒哒 WDD 2026V1 上的静读，以及配套的手机、电脑局域网文件服务。本文约定用户看到什么、点哪里、操作后回到哪里。设备和局域网文件服务的页面设计、交互评审及后续实现以本规范为准。

[正式交互设计稿：全部设备页面与网页文件服务](design/README.md) · [完整功能指南与实机画面](../guides/完整功能指南.md)。交互变更先审设计稿，再改固件；合入时同步使用说明与受影响的配图。

## 一、已确认的设计取舍

正文优先、单侧键、全局下拉、阅读菜单入口和时钟优先为本系统的产品约定。下列三项随 v1.0 一并确认。

| 规则 | 正式约定 | 判断理由 |
| --- | --- | --- |
| A · 小按钮的尺寸 | 通常使用至少 44 × 44 px 的触区。紧凑页脚统一用 68 × 23 px 外框、12 px 字、80 × 36 px 触区 | 缩小占用正文的黑线，同时给拇指留下约 7 mm 的触区高度。以实机边缘点按为准 |
| B · 返回与反馈 | 普通子页只保留左上返回。独立的成功、错误提示页可以在底部中央再放一个紧凑「返回」。可以补救时把这个位置给「重试」等具体动作 | 在书架或设置中直接看得到的新状态可以就地反馈，减少专门为关闭提示而按一次 |
| C · 英语练习 | 长选项可读完再选，「核对答案」才判题。解析可翻页，末页可「重读／继续」。同类操作共用按钮，提交或完成当前步骤的主动作使用黑底 | 阅读选项、选择答案、提交作答是三个不同意图，一次误触不应被记成错题 |

## 二、参考规范及本机取舍

| 参考 | 静读采用的规则 |
| --- | --- |
| Apple 将触控目标、留白和对齐分别考虑，设计建议以 44 pt 为触控参考。[Apple 移动端设计要点](https://developer.apple.com/design/tips/) | 图标可以小，整块热区要大。返回、首页、列表尾箭头都按所处区域响应 |
| Android 建议至少 48 × 48 dp 的触区。Material 的填充、描边按钮表达不同行动优先级。[Android 触控目标](https://developer.android.com/guide/topics/ui/accessibility/apps) · [Material 按钮](https://developer.android.com/develop/ui/compose/components/button) | 页脚统一字、边框、基线和落点。黑底留给本步主动作，描边用于翻页、取消、重读 |
| WCAG 2.2 对网页规定指针目标尺寸及间距例外，并要求拖动功能有简单指针替代方式。[目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) · [拖动替代](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html) | 亮度能点选，书签和快捷设置有可见入口。网页按 CSS 像素核查，设备按实物毫米和原生像素核查 |
| Material 区分已知总量与未知总量的等待。[进度指示](https://developer.android.com/develop/ui/compose/components/progress) | 字体准备可以显示实测进度。网络扫描显示阶段和结果。墨水屏按可见变化刷新，省去旋转动画 |
| Kobo 点正文中央呼出菜单，页角折痕提示本页有书签。[阅读菜单](https://help.kobo.com/hc/en-us/articles/360020494854-About-the-Kobo-eReader-Reading-Menu) · [页角书签](https://help.kobo.com/hc/en-us/articles/360017481214-Bookmark-a-page-on-your-Kobo-eReader) | 正文中央开菜单，书签贴在文章右上角。增删沿用静读约定的正文长按下拉和菜单操作 |

**设备尺度。** 物理屏为 3.7 英寸、240 × 416 原生像素、单色，输入为触屏和一个侧键。按标称对角线估算，显示区约 47.0 × 81.4 mm，1 px 约 0.196 mm。Apple 的 pt、Android 的 dp、浏览器的 CSS px 各有自身定义。以下尺寸均为静读的原生 px。毫米值待有效显示区实测后校准。[硬件与绘制说明](../hardware/WDD-2026V1.md) · [原生画布](../../include/Canvas.h)

## 三、字、线与触区

| 元素 | 视觉规格 | 点击、溢出与对齐 |
| --- | --- | --- |
| 状态栏 | 34 px 高，页名 15 px。电量百分比与电池图标始终在右，读数未知显示「--%」 | 普通子页左上为返回，正文左上为首页，首页省去返回。左侧可点区域至少 40 × 36 px。与下方第一行分开 |
| 列表 | 统一左边距 16 px，主标签 15 px、次要值 12 px。名称左对齐，短状态右对齐，末端为箭头或勾 | 行高至少 44 px，整行可点。进入下一层用箭头，单选用勾，开关显示开／关。长名称省略后可在详情或正文读全 |
| 图标与分隔 | 首页四个入口使用同组 18 × 18 px 单色图标并保留文字。同一组设置项统一使用文字。层级之间留白，必要时加 1 px 横线 | 横线只分组。可点击性由行尾符号或按钮边框说明。图标和标签共同命中同一项 |
| 页脚按钮 | A 项的统一尺寸。上一页在左、下一页在右，已知页数时页码居中。单个返回在中央。按钮用 1 px 边框 | 首末页空出不可用方向，另一侧保持原位。独立动作如书架「添加」另占一行。单页列表回收分页区 |
| 正文字体 | UI 用原生 12／15 px 点阵。书籍 TTF／OTF 按当前字号输出。18–30 px，每档 2 px，默认 20 px | 正文字形按字体度量排版，灰度覆盖率转为单色笔画。检查密笔汉字、标点、中英混排与生僻字。缺字须回退或显示可辨识占位，仍须保留原文位置 |
| 英语练习字体 | 英文默认 Atkinson Hyperlegible Next Medium，连续正文 20 px，列表与辅助文字 15／12 px | 用审核样张中的 Il1、O0、rn/m 和词内留白核对单色输出。普通书籍仍使用读者所选字体。 |

一般独立控件以 **44 × 44 px** 为触区起点，相邻热区不得重叠。紧凑页脚、顶部导航、亮度两端和屏上键盘需要单列尺寸例外。亮度整条属于一个刻度控件。两端各约 38 × 60 px，可逐档校准。键盘按键用独立格，在当前模式下给字符、退格和提交分配不同位置。评审时同时看黑白像素、热区叠图和校准后的实物大小。若拇指容易点错，优先扩触区或拆行。

## 四、导航和按键

| 输入 | 响应 |
| --- | --- |
| 长期休眠时单击侧键 | 唤醒到首页。休眠期间停用时钟定时唤醒，保留静止画面 |
| 锁屏时单击侧键 | 恢复休眠前的页面。这次按压只负责唤醒 |
| 唤醒后单击侧键 | 正文翻至下一页，可分页列表或学习材料前进一页。到末页停住。提交答案、选定某项、删除和开始传输需要点明确按钮 |
| 唤醒后双击侧键 | 保存当前位置后休眠。识别为双击时只执行休眠，唤醒后仍在原页。现有识别窗为 280 ms |
| 普通页面从顶边向下滑 | 打开全局快捷设置，退出后恢复原页面、页码、选择和输入。设置中也应提供可点的入口。锁屏由侧键唤醒，正在准备字体时由等待页接管输入 |
| 点左上返回 | 回到来处。列表进详情再返回，恢复原页。文件子目录返回父目录。阅读菜单的返回回到刚才的正文 |
| 正文内长按后下拉 | 松手切换本页书签。以按下位置区分手势，顶边起手归快捷设置，正文起手才可改书签。沿用约 400 ms 长按、下移至少 48 px。每次接触最多执行一个动作 |

普通点按在松手后生效。移出目标或识别为滑动时取消原点击，避免打开快捷设置后又翻一页。字号、亮度、录入答案等可逆操作直接反馈当前值。删除文件、传输中停服务等有数据后果的操作，在执行前写明对象、后果和取消入口。

## 五、页面如何套用

| 场景 | 页面规则 |
| --- | --- |
| 锁屏与首页 | 锁屏最先能读到时分。月日、星期邻近时钟，年和农历用小字，下方独立排温度、湿度及单位。时钟未校准、传感器无读数均显示实际状态。首页突出「继续阅读」，恢复到上次已显示的位置。首次使用给「从 TF 卡选书」，下方为书架、英语练习、文件管理、设置 |
| 书架、目录、书签、文件管理 | 共用列表和分页。普通列表每页至多六项。书架每本显示进度，文件管理显示当前目录。总数可得时显示「2 / 3」。大目录尚未数清时显示「第 2 页」，按是否还有下一项提供下一页。删除末页唯一书签后回到上一个有效页 |
| 书籍正文与阅读菜单 | 左上小房子保存位置并回首页。正文两侧翻页，中央点开菜单。底部可显示 14 px 高的静态百分比和 1 px 细进度线。关闭后这 14 px 归正文。跳转进度、章节目录、我的书签均在菜单。菜单左上返回，省去底部「继续阅读」「回到首页」。进度跳转从 0% 到 100%，每 5% 一档，共 21 项，每页最多六项。从阅读菜单进入时定位到当前进度所在页，点档位后打开对应正文。普通书籍不提供本页查词 |
| 阅读排版与快捷设置 | 「阅读菜单 → 阅读排版 → 显示阅读进度」管理开关，开启时可选全书或本章。从系统设置进入阅读排版应看到同一状态。书签标签位于正文右上预留边角，避开电量和文字。全局下拉提供亮度、全刷间隔、立即清屏。阅读手势等仅在阅读上下文出现 |
| 亮度与清屏 | 左为暗光、右为强光，两端分别减／加一档。中间 0–10 档可直接点，当前档用加粗线段、游标和数字表示。暗光端到 0 即关前光。用图形承担识别，省出「前光亮度」标签的空间。全刷间隔固定为 5、10、20、50、100 页。「立即清屏」执行一次全刷并返回来处 |
| 系统、Wi-Fi、校时 | 网络、阅读、设备按组排列，日期与时间和 TF 卡使用标准设置行。Wi-Fi 区分已关闭、扫描中、未发现、可用、连接中、已连接和失败。空结果可重新扫描。密码默认遮盖，可显隐、退格、切换大小写／数字／符号。失败后保留本次可编辑输入。日期与时间提供联网和手动校时 |
| 文件服务 | 设备端显示先决条件、启动／停止、地址、配对码、传输结果。缺 Wi-Fi、缺卡、码过期分别给对应下一步。手机和电脑网页提供书籍、字体、英语练习三个明显的上传入口，并可管理 TF 文件。移动端上传、重名、断线、失败和重试都有文字反馈，传输队列一次处理一个文件 |
| 英语学习 | 从课包选篇目，课文里可再换篇。短句、逐句、长文、理解题、错题和查词复用同一页头与分页。卡上的课包和词典支持自行导入。长题干、选项、释义和解析都能读完整。缺课包提示 `/courses/english`，缺词典提示 `/dictionaries` |

### 用同一道题检查一致性

| 此刻用户想做什么 | 左侧或返回动作 | 右侧动作及结果 |
| --- | --- | --- |
| 读完整个长选项 | 「取消」返回题目，保留打开详情前的选择 | 读完可点黑底「选这一项」，回题目显示选中标记 |
| 确认作答 | 可在题目上改选。未选时提示「请选择一个答案」 | 点「核对答案」才判题。连续点按只记录一次 |
| 看答案和原文依据 | 「重读」回到本段原文 | 「继续」前往下一段，篇末回篇目 |

**单页与多页的区别。** 单页直接在页脚排上表中的任务动作。内容跨页时，最底部使用通用分页栏，左侧是「上一页」，中间显示页码，右侧是「下一页」。左上返回始终可用，选项详情中等同于取消。末页在分页栏上方预留一行任务动作，长选项给「选这一项」，解析给「重读／继续」。这与多页书架将「添加」放在分页栏上方使用同一套布局。审核时要走一遍“下一页 → 上一页 → 取消或选定”，并确认末页仍可往回读。

## 六、等待、刷新与恢复

- **换字体、打开 EPUB、恢复进度。** 给出具体阶段，如「正在校验字体」「正在排版本页」。总量可知时用完成量计算进度，未知时显示阶段。字体准备期间明确提示「完成后自动返回」，冻结会打断准备的输入。完成后恢复原上下文。失败交代可行操作，如重新选字体、检查 TF 卡、返回书架。
- **墨水屏反馈。** 一次点击只触发一次动作。选择、勾选、当前档位和正确／错误均用形状或文字表达。局部变化优先合并更新，避免为按下、松开和成功连续全屏闪动。长任务只在阶段或可读进度变化时更新，阅读进度、书签和电量随页面合成。
- **性能验证。** 原生稿检查排版，实机记录从输入到页面稳定的时间，区分全刷和局刷。按用户的两种读法分别测“读完一页再翻”和连续翻 100 页。同书、同字体、同字号比较前后段、P50 和 P95，并标明冷热缓存。

## 七、逐页审核方法

1. **列全页面和状态。** 以固件视图清单为起点，加上手机和电脑文件服务。给每页列出入口、出口、可操作项及适用状态。列表取 0、1、满一屏、多一项和三页。长内容取首、中、末页。涉及网络、卡和字体的流程补齐处理中、失败及恢复。[设备视图清单](../../include/App.h)
2. **按任务走一遍。** 至少覆盖继续阅读并返回、切换字体、分页找书签、换篇并完成长选项作答、密码输错后连接、传书／字体／英语练习、从任一普通页打开快捷设置后返回。记录实际落点、是否额外翻页、输入和选择是否保留。
3. **逐条留证据。** 每项记录“页面与状态｜规范章节｜预期与观察｜原生截图或操作记录｜结论”。结论用「通过」「需修改」「待实机」「经确认的例外」。把错误提交、丢失位置、无法返回或看不全内容列为优先修正项。实物可读性、误触、刷新延迟凭真机记录确认。

**审核顺序**　按本规范逐页审核 → 汇总差异并评审修改稿 → 再进入固件变更和实机验证。版本变更在文首记录，页面如需例外，应写明用户任务、偏离的规则和验证方法。
