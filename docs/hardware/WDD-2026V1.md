# 武哒哒 WDD 2026V1

经典 ESP32，无 PSRAM；8 MiB SPI Flash，DIO，40 MHz。3.7 英寸单色触摸屏为 240 × 416 像素。Arduino 入口委托板级适配管理面板、TF、触摸、传感器、Wi-Fi 和睡眠。[目标配置](../../platformio.ini) · [板级实现](../../src/board/Board.cpp)

| 接口 | 板级配置 |
| --- | --- |
| 墨水屏 HSPI | SCK 18、MOSI 23、CS 5、DC 19、RST 16、BUSY 17 |
| TF 卡 VSPI | SCK 15、MISO 0、MOSI 2、CS 4，挂载在 /sd |
| I²C | SDA 21、SCL 22，200 kHz。环境传感器按地址探测 |
| 侧键、电池 | GPIO39 侧键和睡眠唤醒；GPIO36 电池 ADC |

分区表定义两个各 0x3D0000 字节的应用槽，槽起始地址分别为 0x10000 和 0x3F0000。源码构建生成应用镜像。安装时应先确认目标设备的实读分区表与当前运行槽，选择未运行的应用槽，校验镜像后再选择该槽启动。保留 NVS、引导程序和当前可启动应用。带卡复位若停在串口下载模式，此机型 GPIO0 同时接 TF 的 MISO；暂时取卡复位、看到首页后可插回。[分区表](../../partitions.csv)
