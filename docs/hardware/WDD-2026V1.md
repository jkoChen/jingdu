# 武哒哒 WDD 2026V1

经典 ESP32，无 PSRAM；8 MiB SPI Flash，DIO，40 MHz。3.7 英寸单色触摸屏为 240 × 416 像素。Arduino 入口委托板级适配管理面板、TF、触摸、传感器、Wi-Fi 和睡眠。[目标配置](../../platformio.ini) · [板级实现](../../src/board/Board.cpp)

| 接口 | 板级配置 |
| --- | --- |
| 墨水屏 HSPI | SCK 18、MOSI 23、CS 5、DC 19、RST 16、BUSY 17 |
| TF 卡 VSPI | SCK 15、MISO 0、MOSI 2、CS 4，挂载在 /sd |
| I²C | SDA 21、SCL 22，200 kHz。环境传感器按地址探测 |
| 侧键、电池 | GPIO39 侧键和睡眠唤醒；GPIO36 电池 ADC |

分区表定义两个各 0x3D0000 字节的应用槽，槽起始地址分别为 0x10000 和 0x3F0000。源码构建生成应用镜像。安装时应先确认目标设备的实读分区表与当前运行槽，选择未运行的应用槽，校验镜像后再选择该槽启动。保留 NVS、引导程序和当前可启动应用。带卡复位若停在串口下载模式，此机型 GPIO0 同时接 TF 的 MISO；暂时取卡复位、看到首页后可插回。[分区表](../../partitions.csv)


## 独立时钟与锁屏采样

本机 I²C 七位地址 0x32 实测使用 RX8025T 兼容协议：时间寄存器为 0x00～0x06，顺序为秒、分、时、星期、日、月、年。24 小时制，星期为 `1 << tm_wday`，其余字段为 BCD；保存北京时间，与原厂约定一致。0xE0 在本机返回 NACK，不能套用 RX8025SA/NB 的控制寄存器地址和 12/24 小时解释。原厂函数名称不能单独作为芯片丝印型号的证明。

[RTC 驱动](../../src/board/Rtc.cpp)使用固定七字节时间缓冲和三字节状态缓冲，不申请堆内存。板级适配采用 STOP 后读取，I²C 每次事务限时 40 ms，写入最多两次尝试。写后先核对实际年月日、星期和时间，再清除 0x0E 的 VLF、VDET 标志，保留其他标志；最后再次读取确认，允许跨秒误差 0～2 秒。0x0D TEST 和 0x0F RESET 置位时按手册退出测试和停钟状态，不改动温度补偿及中断配置。启动读取会拒绝失振、停钟、非法日期或星期，避免把不可靠的时间同步到系统。每次定时或侧键从深睡眠唤醒也会重新读取独立 RTC，修正 ESP32 内部 RC 睡眠计时的漂移；读取失败时保留已有系统时间。

联网与手动校时共用该路径。串口 `JD RTC` 直接读取独立时钟并输出状态、时间戳、系统时间及环境数据；`JD RTC RESTORE` 执行与启动相同的硬件时间恢复路径。诊断输出不含网络名称或凭据。通过读取 ESP32 的系统时间不能证明独立 RTC 写入成功。

普通锁屏每分钟由定时器唤醒：电量每次重新读取 GPIO36，温湿度约每五次定时唤醒重新采样，其余分钟使用保留在 RTC 内存中的最近测量值。完整锁屏帧在传感器数据装入后绘制，再进入深睡眠。长期休眠只等待侧键，不定时采样或刷新。GPIO25 的既有启动时序保留；没有证据将它作为 RTC 专用供电控制。

协议参照：[Epson RX8025T 应用手册](https://atta.szlcsc.com/upload/public/pdf/source/20220803/150C0D1072734F0C199E626251B601D2.pdf)、[ESPHome RX8025T 实现](https://github.com/esphome/esphome/blob/dev/esphome/components/rx8025t/rx8025t.cpp)。RTC 的直接读写与秒计数、手动和联网校时，以及锁屏温湿度重采样均已在本机验证。唤醒校正的同机对照中，连续两次定时唤醒的 RTC 与电脑时间差均小于一秒，画面显示当前分钟。侧键唤醒后，系统时间和独立 RTC 也均与电脑时间相符。完全断开主电池的独立后备供电能力需另做断电试验，USB 复位不等于该项验证。
